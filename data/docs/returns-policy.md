# Retail returns policy

In this mock store, customers can request a standard return within 30 days of delivery. Have the order number and item available for the returns team. If available, include the original accessories and packaging.

The returns team confirms item eligibility and provides return instructions. For an item that has already been returned, use the order number to check its current refund status. For a suspected defect beyond the standard return window, contact support for a warranty assessment.
